# 37. TESTING DISCIPLINE

Keep the existing verification philosophy.

Every new major system needs:
1. implementation
2. runtime test
3. regression test
4. mutation test
5. visual inspection

Mutation protocol:

1. identify the behavior
2. apply mutation
3. assert mutation actually changed the file/behavior
4. run the check and require failure
5. restore and require pass

A mutation that fails to apply is NOT a pass.

A skipped mutation is NOT verified.

Static source-string checks are insufficient when runtime behavior can be tested.
